# BNK AppSec

**Desenvolvimento de software com segurança desde a concepção.**

O BNK AppSec é um projeto acadêmico desenvolvido em equipe, com foco na construção de soluções digitais seguras, aplicando boas práticas de engenharia de software, desenvolvimento seguro e colaboração.

## Objetivos

- Desenvolver uma aplicação web segura.
- Aplicar princípios de Security by Design.
- Implementar boas práticas de desenvolvimento.
- Promover colaboração utilizando Git e GitHub.
- Integrar segurança ao ciclo de desenvolvimento.

## Páginas do portal

O portal do Bunker AppSec é formado por quatro páginas:

- `index.html` — página principal: equipe, missão/visão/valores, ações de extensão e localização;
- `quem-somos.html` — história da startup e detalhes de cada ação de extensão;
- `personas.html` — perfil profissional de cada integrante da equipe;
- `contato.html` — formulário com Nome, E-mail, Assunto e Conteúdo, enviado por `enviar.php` para o Scrum Master.

## Tecnologias

- HTML5
- CSS3
- JavaScript

Novas tecnologias serão documentadas conforme a evolução do projeto.

## Colaboração

O desenvolvimento é realizado de forma colaborativa por meio de branches, commits e Pull Requests.

Consulte o arquivo `CONTRIBUTING.md` para conhecer as orientações de contribuição.

## Segurança

A segurança é uma prioridade durante todo o ciclo de desenvolvimento.

Não publique senhas, tokens, chaves privadas ou informações confidenciais neste repositório.
